# data/ 폴더 안내

경남대 주변 보행 안전 지도에 쓰는 데이터와, 같은 결과를 다시 만드는 방법입니다.
데이터는 DB 없이 **정적 JSON 파일**로 제공합니다(화면용 파일이 합쳐서 약 0.7MB).

## 점수 범위
학교(35.1816, 128.5532)를 중심으로 한 변 3km 정사각형(±1,500m)입니다. 모서리는 학교에서 약 2.12km 떨어져 있습니다.
(예전에는 반경 1.4km 원이었는데, 원으로 자르면 도로망이 끊겨서 경로 탐색이 안 되어 사각형으로 넓혔습니다.)

### graph.json 읽는 법
- 노드 그룹: `0` = 경로 탐색에 쓰는 본 도로망, `1` = 본 도로망과 끊긴 작은 덩어리, `2` = 산길(path/track)만 닿는 노드
- 간선의 구간 id는 `risk_segments.geojson`의 `properties.id`입니다. 점수·요소값(`r`)은 거기서 찾습니다.
- 등급 번호는 `meta.hw` 배열의 위치입니다. 산길 등급은 `meta.trailHw`.
- 산길 간선도 모두 들어 있습니다. 경로 탐색에서 뺄지는 사용하는 쪽이 정합니다(아래 참고).
- 구간의 점수는 요소값(`r`)과 가중치(`points.json`의 `meta.weights`)로 다시 계산할 수 있습니다(최대 오차 0.5점, 반올림 때문).
  가중치만 바꾸면 낮/밤 점수를 브라우저에서 다시 계산할 수 있습니다.

### 도로망 연결에 대해 알아둘 것 (측정값)
- 산길까지 포함하면 도로망의 99%(2,963/2,995노드)가 하나로 이어집니다.
- 산길(path/track)을 빼면 본 도로망이 1,753노드이고, 남서쪽(예곡동 방향, 220노드)과 동쪽 해양신도시 보행로(124노드)가 끊깁니다. 이 두 곳은 산길을 통해서만 본 도로망과 이어져 있습니다.

## 다시 만드는 방법

```bash
node scripts/build-risk.mjs
```

- 위 "제외" 파일 3개가 `data/`에 있어야 합니다. `osm_roads_knu.json`은 없으면 스크립트가 Overpass에서 자동으로 받습니다.
- 점수 설정(가중치, 거리 기준, 도로 등급 점수, 범위)은 `scripts/build-risk.mjs` 맨 위에 있습니다.
- 경로 탐색 시험(최단 경로와 안전 경로 비교): `node scripts/probe-routes.mjs [쌍 개수] [α]`
- 데이터 점검(원본 점 데이터, 도로, 점-도로 연결, `graph.json`이 서로 맞는지 21개 항목): `node scripts/audit-data.mjs`
  빌드를 다시 돌린 뒤에는 이 점검도 돌려서 "문제 0건"인지 확인합니다.

## 데이터 처리 규칙 (점검에서 확인한 것)
- **점은 가장 가까운 도로 한 곳에만 배정**합니다(5m 이내 차이면 함께). 같은 이름·같은 등급의 도로선(상·하행 등)은 한 도로로 봅니다.
  예전에는 구간에서 40m/100m 안의 점을 모두 셌는데, 골목이 촘촘한 곳에서 옆 도로의 점이 섞였습니다.
- **주소의 동과 좌표 위치가 크게 어긋난 보안등은 제외**합니다(같은 구·동 보안등의 중앙 위치에서 max(3km, 중앙 반경×4)보다 멂).
  현재 1개(현동092: 주소는 현동인데 좌표는 학교 근처)가 제외됩니다.
- CCTV는 설치 목적이 생활방범·어린이보호인 것만 점수에 반영합니다.
- 점검에서 확인된 한계: 도로 구간의 45%는 OSM에 이름이 없고, CCTV 도로명주소와 비교했을 때 OSM에 그 골목 이름이 없는 경우가 있습니다(좌표 오류는 아님).

| 데이터 | 출처 | 기준일 | 받는 방법 |

| 보안등 | 공공데이터포털 [전국보안등정보표준데이터](https://www.data.go.kr/data/15017320/standard.do) 중 "경상남도_창원시_보안등정보" 파일 (이용허락범위 확인 필요) | 2025-02-12 | 해당 페이지의 데이터 목록에서 "창원"을 검색해 파일 CSV 다운로드 |
| CCTV | 공공데이터포털 [전국CCTV표준데이터](https://www.data.go.kr/data/15013094/standard.do) → 행정안전부 지방행정 인허가 데이터 센터 | 2026-05-02 | 센터의 CCTV정보 페이지에서 지역(경남 창원시, 코드 5670000)을 골라 "지역별 파일 다운로드" |
| 교통사고 다발지 | 공공데이터포털 [전국교통사고다발지역표준데이터](https://www.data.go.kr/data/15029185/standard.do) (도로교통공단, 2012~2020년 항목) | 2025-09-24 | 데이터 표의 검색 조건을 "사고다발지역 시도시군구 = 창원"으로 조회(140건). 학교 2.4km 이내 9건을 화면에서 읽어 파일로 저장했고, 사고건수 합(38)과 위도 합을 브라우저 값과 대조해 확인함 |
| 도로망 | OpenStreetMap contributors (ODbL), Overpass API | 받은 날 | `build-risk.mjs`가 학교 중심 3km 사각형을 자동 조회 |
| 학교 좌표 | OSM (35.1816, 128.5532) | | 스크립트 상단 `CAMPUS` |

주의:
- 보안등 파일에는 도로명주소·설치연도가 없고(전체 비어 있음), 밝기·고장 정보도 없습니다.
- CCTV는 공개 대상 일부만 포함됩니다. 창원시 전체 3,734건입니다.
- 사고다발지는 2012~2020년 자료라 최신 상황과 다를 수 있고, 시간대 정보가 없습니다.
- 공공데이터포털 다운로드는 로그인이나 보안문자(CAPTCHA)를 요구할 수 있습니다. 그 경우 직접 진행해야 합니다.

## 지도 (카카오맵)
- `map.html`은 카카오맵 JavaScript SDK를 씁니다. 키는 파일 안에 있고, 카카오 개발자 콘솔의
  JavaScript SDK 도메인에 등록된 주소(`http://localhost:5173`, 배포 주소)에서만 동작합니다.
- 로컬 실행: `node scripts/serve.mjs` 후 `http://localhost:5173/map.html` (127.0.0.1은 안 됨)
- 발급 절차: 저장소 루트의 `카카오맵-키-발급-안내.md`
